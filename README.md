# Cliente AgarV1 - Documentación Técnica

Este proyecto es un cliente de Agar.io escalable y moderno, diseñado para ser compatible con servidores **MultiOgarII** utilizando el **Protocolo 6**.

## 🎮 Controles Implementados
-   **Movimiento**: Ratón.
-   **Dividirse (Split)**: Tecla `Espacio`.
-   **Dar Masa (Feed)**: Tecla `W`.
-   **Menú/UI**: Tecla `Esc` (alternar menú).
-   **Zoom Manual**: Rueda del ratón (`Mouse Wheel`).
-   **Otras acciones**: Teclas `Q`, `E`, `R` preparadas para macros/comandos del servidor.

## 🛠️ Cómo Ejecutar
1. Asegúrate de tener un servidor compatible (ej. `MultiOgarII`) corriendo en `ws://localhost:8080`.
2. Abre `index.html Live Server para test` en un navegador moderno .
3. ¡Ingresa tu nick y domina el mapa!
